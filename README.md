# CP-1-Sistema-de-Monitoramento-Fretado
Tem como objetivo fornecer informações em tempo real sobre a operação do transporte fretado oferecido pela faculdade aos seus alunos.

## 📌 Descrição do Problema
Muitos alunos dependem do serviço de fretado oferecido pela faculdade para o deslocamento entre o ponto de embarque e o campus. No entanto, atualmente não existe uma forma prática e centralizada de informar aos estudantes se o ônibus já está no ponto, quanto tempo falta para a saída ou quanto tempo falta para o próximo veículo chegar. 
Além disso, o monitor responsável pelo controle do fretado precisa organizar manualmente o tempo de espera do ônibus, o embarque e a saída, o que pode gerar falhas de comunicação com os alunos. 

## 🚀 Solução Proposta
Desenvolvimento de um Sistema de Monitoramento de Fretado Universitário, composto por duas interfaces principais que permite à alunos terem visibilidade da localização do ônibus, tempo de espera (chegada/partida). Enquanto o monitor age como administrador, registrando a chegada do ônibus, iniciando o temporizador de espera, registrando saída antecipada em caso de lotação e informando a previsão de chegada do próximo ônibus.
